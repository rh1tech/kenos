Support

Updated 27 September 2026

Write to support@rh1.tech and a person will answer. Common topics are below.

Requirements

  • macOS 26+. Kenos uses APIs and interface behaviour introduced with that release.
  • Network access for browsing, and for Kenos’s own update check and optional filter-list refresh.
  • Camera and microphone only when a website asks — you approve each site in Kenos.

Getting started

  • ⌘, opens Settings — language, layout, shield, passwords, updates.
  • ⇧⌘S switches tabs between the top strip and the sidebar.
  • Import passwords, bookmarks and recent addresses from Chrome-family browsers on the welcome screen or in Settings › Passwords.

Passwords and passkeys

Saved passwords live in the macOS keychain under Kenos. Viewing them may ask for Touch ID. Passkeys need an Apple browser entitlement; builds without it keep sites on ordinary passwords and say so in Settings.

Ad blocking

Settings › Shield turns the content blocker on or off. If a site breaks, pause blocking for that host, or press Update on the filter lists after a network change.

Updates

Kenos checks https://kenos.rh1.tech/appcast.json about once a day. You can check manually in Settings › Kenos. Downloads come from this same site under /download/.

Contact

Email support@rh1.tech. Include the version and build from Settings › Kenos (or Help › Send Feedback, which opens a draft with those filled in).
